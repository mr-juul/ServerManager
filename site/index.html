Why this project exists

Update safe

Program data sits in ProgramData/ServerManager instead of inside the app folder, so an upgrade does not wipe your servers.

Ready checks

Steam, Java, dedicated server presence, and server configuration are all surfaced clearly instead of hidden in logs.

Built for Windows

The app is designed for Windows desktop use, including .bat-based server launch, logs, world backups, and process control.

Typical workflow

  1. Install or open Server Manager
  2. Let it detect Steam and libraries
  3. Choose a game and run setup
  4. Fix missing dependencies automatically
  5. Create a server instance and launch it
